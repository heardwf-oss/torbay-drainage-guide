What each assessment covers

  1. Site and constraintsEnter the grid reference. Open the site maps and record any constraints.
  2. Key numbersPut each document’s figures side by side. Mismatches and figures outside the rule limits are flagged.
  3. ChecksRecord the outcome and finding for each of the 126 checks.
  4. Summary and requestWrite the conclusion and the request for further information.
  5. Consultation responseChoose the recommendation. Reasons fill from your findings. Copy it or print it.
  6. Earlier roundsEach completed round is kept, so resubmissions start from the last one.
